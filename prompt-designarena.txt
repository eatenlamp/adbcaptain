Build a modern one-page landing site for **ADB Captain** — a free, open-source (FOSS) Android app that turns your phone into a full ADB toolkit. No root, no computer needed.

### About the product
- **Name:** ADB Captain. Tagline: *"A powerful, rootless ADB toolkit for Android, powered by Shizuku."*
- **What it does:** runs real ADB commands right on your phone via Shizuku. Think of it as a command deck for your own device.
- **Who it's for:** power users, tinkerers, developers, and anyone who likes cleaning up their phone without trusting some sketchy "bloat remover" app.

### Features (your section material)
1. **Terminal** — a real ADB console in the app: run `pm`, `am`, `dumpsys`, `settings`, `input`, and more. Command history with smart autocomplete, ANSI-colored output.
2. **Apps** — full package manager: browse every installed app, search, filter User/System, and get a plain-language safety rating for each one: safe to remove, remove only if needed, don't touch. Actions: force-stop, clear data, disable, uninstall.
3. **Devices** — live device info: model, Android version, API level, battery, connection status. Reboot with a confirmation dialog. One-tap screenshots saved to DCIM/ADBCaptain.
4. **Logcat** — live system log viewer with level filters (Verbose to Fatal), text search, smart auto-scroll, tap-to-copy.
5. **Sideload & Tools** — install APKs from storage, screenshots and screen recording with an elapsed timer, device controls (wake, unlock, Wi-Fi, Bluetooth, airplane mode, volume), type text and open links.
6. **Settings** — dark theme, command history toggles, English/Russian UI, one-tap Shizuku status check.

### Design direction
- **Theme:** a dark "ocean / ship's bridge" mood — deep navy, accents of copper or teal. Premium, modern, minimal. Should feel like you're at the helm of your device, not inside a corporate chart.
- **Hero:** bold headline, tagline, Download buttons (F-Droid / GitHub Releases / RuStore), and a phone mockup showing the app UI.
- **Sections:** features as icon cards, a simple "How it works" in 3 steps (install Shizuku -> start the service -> press go), app screenshots, compatibility note (Android 7.0+, API 24+), open-source/footer area, FAQ.
- **Motion:** subtle hero animation, light scroll reveals, soft hover states. Nothing flashy or "template-y."
- **Mobile-first**, must look natural on any screen.
- Typography: Inter for UI text and JetBrains Mono for small "terminal" accents in headings.

### Content details
- Download links: use `#` placeholders for F-Droid, GitHub Releases, RuStore.
- Open Source section: AGPL-3.0-or-later badge, "100% FOSS" note, GitHub repo link.
- Shizuku section: one or two honest sentences on why it's needed (link: shizuku.rikka.app) plus an "Install Shizuku" button.
- FAQ (5-7 items): Need root? No. Why Shizuku? Is it really free? Any ads/tracking? No. Minimum Android version? Is there a Russian UI? Yes.
- Copywriting style: confident, friendly, technical. Short sentences. No filler words, no corporate clichés.

### Most important requirement
**The copy must not read like it was written by AI.** Write like a developer describing a tool they actually use and are proud of. Vary sentence length, keep it a little rough around the edges, use concrete details, no generic marketing fluff, no buzzwords like "seamless", "intuitive", "effortless", "unlock the full potential". No lorem ipsum anywhere — real text only.

**Deliver:** a complete, working site with real copy, working nav, all sections, and responsive layout.
